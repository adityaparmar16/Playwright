WASTE NOT GLOBAL (WNG) - TRANSLATION ISSUES
============================================
Source      : Automated translation baselines (tests/WNG/Translations/baselines)
Captured    : 20 Nov 2026
Environments: WNG Global Dev and Stag (issues seen in both)
Languages   : Français (Canadien), Deutsch, Português, Italiano, Türkçe, Polski
Screens     : Home page, Analytics Dashboard, Reports modal (Now / Schedule), Send Now message

Steps to reproduce (all tickets):
  1. Log in as Entity / Unit / Org / Global admin
  2. Hamburger menu -> My Account -> Language -> select <language> -> Save
  3. Open Home page, Analytics Dashboard and Reports modal (Now and Schedule)

Note: "Suggested" fixes should be confirmed by a native speaker / translation vendor.
"#" in the texts below stands for a number.

TICKET 2 - Dropdown placeholders built as "Select a" + label -> wrong grammar
----------------------------------------------------------------------------
Where   : Analytics Dashboard filters (Unit, Kitchens, Profiles, Tablets, Entity, Organisation)
Current :
  FR  "Sélectionner un CUISINES", "Sélectionner un PROFILS", "Sélectionner un Tablettes",
      "Sélectionner un Unité", "Sélectionner un ENTITÉ", "Sélectionner un Organisation"
  DE  "Wählen Sie eine Küchen", "Wählen Sie eine Profile", "Wählen Sie eine Tablets"
  PT  "Selecione uma Comprimidos", "Selecione uma Cozinhas", "Selecione uma Perfiles"
  IT  "Selezionare una Cucine", "Selezionare una Profili", "Selezionare una Tablets",
      "Selezionare una Entita"
  TR  "Bir seçim yapınız MUTFAKLAR", "Bir seçim yapınız PROFİLLER", "Bir seçim yapınız Varlik"
  PL  "Wybierz Jednostka", "Wybierz Organizacja", "Wybierz Nazwa podmiotu" (wrong grammatical case)
Root cause: the placeholder joins a fixed "Select a" with the label, so article/gender/case
            cannot agree.
Suggested: one complete translated placeholder string per filter
           (e.g. FR "Sélectionner des cuisines", DE "Küchen auswählen", PL "Wybierz jednostkę"),
           or a neutral form such as "Cuisines : sélectionner".
